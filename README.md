# NEXUS: World Simulator

NEXUS — стратегический симулятор мира с детерминированной симуляцией и подключаемым AI-слоем.

Сначала разрабатываем и тестируем Windows-версию. Android портируем только после стабилизации desktop-версии.

Порядок: desktop UI → карта мира → страны и провинции → экономика и население → приказы → сохранения → дипломатия/законы/события → AI API → Android.

AI не является источником игровых цифр: он переводит намерение игрока в структурированные команды, а симуляция остаётся авторитетной.
