# Система приказов

Приказ — структурированное действие игрока.

## Строительство

Доступны первые типы:

- обычный завод — 6 месяцев;
- электронный завод — 8 месяцев;
- электростанция — 10 месяцев.

Каждый строительный приказ содержит:

- провинцию;
- тип объекта;
- срок строительства;
- стоимость;
- количество рабочих мест;
- бонус к производству.

## Жизненный цикл

1. Игрок создаёт приказ.
2. Валидатор проверяет деньги и параметры.
3. Стоимость списывается из казны.
4. Проект попадает в очередь строительства.
5. Каждый игровой месяц срок уменьшается.
6. После завершения проект изменяет провинцию и занятость.

В будущем естественный язык будет переводиться AI-слоем в эти же структурированные приказы.
