# Правила симуляции — первый прототип

## Основные показатели страны

- население;
- рабочая сила;
- занятые;
- безработные;
- бюджет;
- доходы;
- расходы;
- благосостояние;
- доверие;
- коррупция.

## Провинция

Каждая провинция содержит:

- население;
- инфраструктуру;
- рабочие места;
- производство;
- доход;
- расходы;
- уровень развития.

## Время

Базовый шаг симуляции — один игровой месяц.

Все системы должны использовать игровую дату, а не реальное время компьютера.

## Детерминизм

При одинаковом состоянии мира, наборе приказов и seed генератора случайных событий результат должен быть одинаковым.
