# Архитектура NEXUS

## Основной принцип

Игра разделена на несколько слоёв:

1. **Симуляция** — единственный источник истины для состояния мира.
2. **Приказы** — структурированные действия игрока.
3. **События** — изменения, возникающие из симуляции и внешних факторов.
4. **Интерфейс** — отображает состояние мира и принимает решения игрока.
5. **AI** — переводит естественный язык в допустимые игровые приказы.

## Поток команды

`Игрок → AI/интерфейс → проверка приказа → симуляция → новое состояние мира → UI`

AI не должен напрямую менять значения экономики или населения.

## Первый вертикальный срез

Начинаем с одной страны и десяти провинций.

Каждый игровой месяц:

1. собираются приказы;
2. проверяется их валидность;
3. рассчитываются расходы;
4. применяются изменения;
5. рассчитываются экономика и население;
6. создаются события;
7. игровая дата увеличивается на месяц;
8. состояние можно сохранить.
