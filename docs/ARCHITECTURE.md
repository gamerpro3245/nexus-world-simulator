# Архитектура NEXUS

Симуляция является источником истины. UI и AI не меняют игровые цифры напрямую.

Слои:
- simulation — состояние мира и расчёты
- orders — структурированные приказы
- ui — интерфейс
- ai — адаптеры AI-провайдеров
- data — данные стран, ресурсов, законов и событий

AI API в будущем будет подключаться через единый интерфейс. Ключи не хранятся в репозитории. Игрок сможет выбрать провайдера и указать API key локально.

Windows — основная платформа разработки. Android добавляется после стабилизации desktop-версии.
